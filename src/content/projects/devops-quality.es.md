## Automatización, Cloud & Seguridad

Entrega automatizada del código hasta producción:

- **Pipelines CI/CD** para pruebas unitarias, creación de artefactos y build de contenedores
- **Terraform** para el aprovisionamiento versionado de redes y bases de datos
- **Docker** y **Kubernetes** para orquestación y escalabilidad
- **SonarQube** y **Checkmarx** para mitigación de vulnerabilidades
- Control de accesos con **AWS IAM** bajo el principio de menor privilegio
